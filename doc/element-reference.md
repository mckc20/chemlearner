# Offline element reference, edition 2

Issue #30 adds profiles to the reference table; quiz cells retain their existing behavior. All profile data ship in the application bundle. Opening a compound still uses the existing network-dependent structure viewer. Offline access means that a loaded application can open every profile without fetching data; this does not add a service worker or an offline installation mechanism.

## Sources and attribution

Retrieved 2026-10-12. The bundled `src/data/elements/reference.json` includes 118 elements, 335 explicitly selected ground-state isotopes, and 13 supported monatomic ion configurations. Each property retains its source provider, supporting URL, original value, units, relevant conditions, and measured/predicted/unknown status. The UI calls measured entries “reported reference values”; this does not imply that every reported number is a direct measurement. A profile gathers its actual citations in one collapsed Sources panel. The Help page explains provider roles in English and German.

- **PubChem**, National Center for Biotechnology Information: [periodic table API](https://pubchem.ncbi.nlm.nih.gov/rest/pug/periodictable/JSON) and element PUG View records (`https://pubchem.ncbi.nlm.nih.gov/rest/pug_view/data/element/1/JSON`, substituting atomic numbers 1–118). See [Kim et al., PubChem Periodic Table and Element Pages](https://pmc.ncbi.nlm.nih.gov/articles/PMC8276875/). PubChem aggregates values contributed by CIAAW, Jefferson Lab, LANL and NIST; the contributing name is retained for each selected property. Jefferson Lab's current direct pages restrict automated access, and current LANL pages do not always show the historical value. The profile links to the exact PubChem element record preserving the value and its contributor attribution. Original bilingual teaching notes in `editorial.js` summarize element records rather than reproduce upstream articles. PubChem CIDs and formula checks for bundled standalone compound examples are recorded in `example-citations.json`. Do not assume a blanket license covers all contributed content.
- **NIST Atomic Spectra Database**, ground states and ionization energies: [ASD](https://physics.nist.gov/PhysRefData/ASD/ionEnergy.html), DOI [10.18434/T4W30F](https://doi.org/10.18434/T4W30F). The neutral configurations available through Z=108 and the selected positive-ion configurations were expanded from the source's shorthand. Remaining neutral configurations come from PubChem. The transformation expands cores and sorts subshells, but does not fill orbitals using an Aufbau algorithm. See [NIST copyright and licensing terms](https://www.nist.gov/open/license); Standard Reference Data and other NIST works have distinct terms, and this derived collection does not claim ownership of upstream data.
- **IAEA Nuclear Data Services**, [LiveChart API](https://iaea-nds.github.io/lc_api_notebook/): ground-state data, evaluated nuclear properties and atomic masses. [IAEA disclaimer](https://www-nds.iaea.org/disclaimer.html): data are distributed as consensus values without a guarantee of accuracy or fitness for a particular scientific application. Evaluation cutoff dates are retained per isotope. The data are transformed into a selected teaching collection, not a complete nuclear database.
- **OpenStax, Chemistry: Atoms First 2e**, [Electronic Structure of Atoms](https://openstax.org/books/chemistry-atoms-first-2e/pages/3-4-electronic-structure-of-atoms-electron-configurations): the ion-filling rule used to derive closed-shell fluoride and chloride configurations from the PubChem noble-gas occupancies. [Book license and attribution](https://openstax.org/books/chemistry-atoms-first-2e/pages/preface). The page does not directly list those two anions. Their records are marked derived; oxidation states are not converted into ion choices.

## Scientific and editorial decisions

- Isotope selection includes all IAEA records with positive natural abundance, plus the explicit educational and representative isotope lists in the builder. The resulting selection and default are stored in the bundled artifact. It includes tritium, carbon-14, fluorine-18, sodium-22, phosphorus-32, cobalt-60, strontium-90, technetium-99, iodine-131, caesium-137, uranium isotopes, plutonium-239 and americium-241. Metastable states are not included; the technetium note distinguishes Tc-99m from the ground-state table.
- Natural abundance determines the default only where the source supplies one. Otherwise a representative mass number is explicitly chosen. Average atomic weights never determine neutron counts. Representative mass numbers supplied instead of standard atomic weights are bracketed and labeled separately.
- IAEA atomic masses and uncertainties are converted from micro-u to u using decimal arithmetic. Parenthetical half-life uncertainties and inequality operators are preserved. Systematics flags identify predicted isotope masses. Source intervals and uncertainty notation in physical properties are retained, not rounded away.
- Neutral superheavy configurations/properties from Z=104 are marked predicted conservatively. Actual missing quantities are shown as unavailable. There is no fabricated density, temperature, radius or isotope abundance. A blank abundance does not become zero.
- Density and transition-temperature records often lack pressure, temperature or allotrope qualifiers. Density identifies missing temperature, pressure and material-form information; transition temperatures identify missing pressure. Atomic reference properties carry no generic conditions disclaimer. Helium solidification and carbon phase transitions have additional notes to prevent misleading ambient-pressure interpretations. Bulk values never change with isotope or ion selection.
- Detached series have scientific periods 6/7 and unassigned group numbers; their conventional series block is f. This is separate from the existing grid's layout row/column values. It does not claim to settle the group-3 convention or infer the differentiating orbital from series membership.
- Orbital boxes apply simplified Hund-style arrows to sourced subshell occupancies of isolated ground states. They are not molecular orbitals or a complete angular-momentum model. The nucleus drawing caps decorative dots; exact proton/neutron counts are always textual. Animation speed has no physical interpretation.
- Compound matching parses full formulas, including groups, hydrates, subscripts and terminal charges. It extracts symbols only; it does not calculate molecular mass or use formula equality as chemical identity. Unsupported formulas are excluded. Curated links use stable library IDs.

## Rebuilding the reference

Place these downloads in a local snapshot directory:

1. `chem-elements.json`: PubChem periodic table JSON.
2. `chem-reference/1.json` through `118.json`: PubChem PUG View element records. Respect rate limits; at most three simultaneous requests, with retries/backoff.
3. `chem-nist.csv`: [NIST ground-configuration CSV query](https://physics.nist.gov/cgi-bin/ASD/ie.pl?spectra=H-Og&units=1&format=2&order=0&at_num_out=on&sp_name_out=on&ion_charge_out=on&el_name_out=on&shells_out=on&level_out=on&e_out=0).
4. `chem-isotopes.csv`: `https://nds.iaea.org/relnsd/v1/data?fields=ground_states&nuclides=all`. Use the documented `User-Agent: Livechart/1.0` header.

Run `python3 scripts/build-element-reference.py /path/to/snapshots`. This runs offline and writes only the bundled reference; an optional second argument selects another output file. Run `python3 scripts/audit-element-reference.py /path/to/snapshots` to compare every generated record with the archived inputs and verify all 121 input hashes. For this edition the audit checked 804 populated property values, 335 selected isotope records and 13 ions, plus 47 standalone example placements representing 46 distinct PubChem CIDs. All 84 CIAAW-attributed atomic weights also matched the commission's live standard-weights table. A link check covering all profile and Help citations plus the bundled compound-library links checked 291 distinct URLs; every URL returned HTTP 200 on 2026-10-12. A successful link check does not itself establish that the page supports a particular value. On future refreshes, update the edition and retrieval date in the builder, review source/term changes and generated diffs, and rerun the citation checks. Raw downloads are not required at runtime.

Run `npm test -- --run`, `npm run lint`, and `npm run build`. Tests validate all isotope/ion particle totals, source metadata, selected known configurations, formula grammar, all 472 element/tab combinations, dialog interaction and compound return state. Check real-browser reduced motion, both themes/languages, mobile scrolling and offline opening after loading the application.
